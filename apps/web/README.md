# Meeting Assistant Web

React + Vite + TypeScript frontend for the lightweight meeting assistant.

## Run

```bash
npm install
npm run dev
```

The current implementation uses local mock data and follows the `stitch_` prototype structure:

- login / enter workspace
- meeting topic list
- pre-meeting briefing
- live recording with assistant panel
- AI report generation state
- meeting overview
- full transcript
- meeting action items
- my action matrix
- settings with backend-only LLM configuration status

## Checks

```bash
npm run lint
npm run build
```
